# Sistema de Gerenciamento de Restaurante

## Integrante

* Vinicius da Silva Pereira Fagundes

## Tema

**Sistema de Gerenciamento de Restaurante**

## Descrição

O projeto consiste no desenvolvimento de um banco de dados para o gerenciamento das informações de um restaurante.

O sistema terá como objetivo armazenar e organizar informações relacionadas aos clientes, funcionários, mesas, pratos, categorias, pedidos, itens dos pedidos e pagamentos.

Através do banco de dados será possível registrar os pedidos realizados pelos clientes, os pratos que fazem parte de cada pedido, os funcionários responsáveis pelos pedidos, as mesas utilizadas e os respectivos pagamentos.

O projeto será desenvolvido utilizando SQL e a modelagem do banco de dados será realizada no MySQL Workbench.
